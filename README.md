# HVAC Quote Studio

A self-contained, responsive prototype for creating four-option HVAC estimates and customer-facing proposals.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Select Pages in the left sidebar.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/(root)`, then Save.
5. Wait for the Pages deployment to complete. The site URL will be `https://mexiaeon.github.io/hvac-quote-studio/`.

## Prototype limitations

This is a front-end demo, not production SaaS. Drafts are saved only in the current browser. It does not include accounts, cloud sync, subscription billing, email delivery, or secure proposal links. Use sample data only until a secure backend and appropriate privacy/security controls are implemented.
